POWERec(模态提示+弱模态增强)

POWERec论文总结

当前领域存在的问题

  1. 多模态用户兴趣建模效率低：现有方法为每个用户在不同模态上使用独立的嵌入向量，忽略了不同模态间用户兴趣的潜在关联，且显著增加了内存开销。
  2. 弱模态学习不足：现有方法无法确保所有模态的用户兴趣都被充分学习，某些模态（弱模态）可能学习不足，导致预测不可靠，影响最终推荐效果。

现有做法

  1. 早期融合方法：先将物品的多模态特征融合为一个嵌入向量，再基于该向量预测用户评分。缺点是无法建模用户对不同模态的特定兴趣。
  2. 晚期融合方法：先分别学习用户对每个模态的评分（模态特定用户评分），再融合这些评分得到最终评分。虽然性能较好，但仍存在上述两个问题。

本文提出的方法（POWERec）

1. 基于提示的多模态用户兴趣学习（Multimodal Prompted User Interest Learning）

  • 基准模型：使用单一用户嵌入向量作为基础用户表示。
  • 创新点：
    • 模态提示（Modality Prompts）：为每个模态设计少量可学习的提示嵌入向量（Prompt Embeddings），通过将提示向量与基础用户嵌入相加，生成不同模态的用户表示。
    • 作用：通过共享的基础用户嵌入和模态特定的提示，既建模了模态间的关联，又减少了内存开销。

2. 弱模态增强训练（Weak-Modality Enhanced Training）

  • 创新点：
    • 弱模态识别：计算用户对正负物品在每个模态上的评分差异，差异最小的模态被识别为弱模态。
    • 硬负样本生成：构造一个仅在弱模态上与正样本不同的硬负样本。
    • 弱模态正则化：通过优化目标函数，强制模型在弱模态上更好地区分正样本和硬负样本。
  • 作用：增强弱模态的用户兴趣学习，确保所有模态的预测都可靠。

实验效果

在Amazon的Baby和Clothing数据集上，POWERec显著优于现有方法（如DualGNN、SLMRec等），同时减少了内存开销。例如，在Clothing数据集上，Recall@10提升了1.8%，NDCG@10提升了1.7%。

方法步骤总结

1. 问题定义

  • 输入：
    • 用户集合 U\mathcal{U}U，物品集合 I\mathcal{I}I，模态集合 M\mathcal{M}M。
    • 每个用户 u∈Uu \in \mathcal{U}u∈U 有历史交互物品 Iu\mathcal{I}_uIu​。
    • 每个物品 i∈Ii \in \mathcal{I}i∈I 有多模态特征 {fim∣m=1,...,∣M∣}\{f_i^m | m = 1, ..., |\mathcal{M}|\}{fim​∣m=1,...,∣M∣}，其中 fimf_i^mfim​ 是第 mmm 个模态的特征。
  • 目标：基于用户交互和多模态特征预测用户对物品的评分 yu,iy_{u,i}yu,i​。

2. 方法框架（POWERec）

框架包含两个核心组件：

  1. 多模态提示用户兴趣学习（Multimodal Prompted User Interest Learning）
  2. 弱模态增强训练（Weak-Modality Enhanced Training）

2.1 多模态提示用户兴趣学习

(a) 物品多模态嵌入（Item Multimodal Embedding）

  1. 模态特征编码：对物品 iii 的第 mmm 个模态特征 fimf_i^mfim​，通过多层感知机（MLP）映射到 ddd 维空间：

    eim=Tanh(W2m(Tanh(W1mfim+b1m))+b2m)e_i^m = \text{Tanh}(W_2^m (\text{Tanh}(W_1^m f_i^m + b_1^m)) + b_2^m)eim​=Tanh(W2m​(Tanh(W1m​fim​+b1m​))+b2m​)

    其中 Wlm,blmW_l^m, b_l^mWlm​,blm​ 是第 mmm 个模态的MLP参数，Tanh\text{Tanh}Tanh 是激活函数。

  2. 多模态拼接：将所有模态嵌入拼接为物品的多模态嵌入：

    ei=[ei1,...,ei∣M∣]e_i = [e_i^1, ..., e_i^{|\mathcal{M}|}]ei​=[ei1​,...,ei∣M∣​]

(b) 用户多模态嵌入（User Multimodal Embedding）

  1. 基础用户嵌入：每个用户 uuu 用一个共享的基础嵌入 fu∈Rdf_u \in \mathbb{R}^dfu​∈Rd 表示。
  2. 模态提示（Modality Prompts）：
    • 为每个模态 mmm 定义可学习的提示嵌入 Pm=[p1m,...,pQm]P^m = [p_1^m, ..., p_Q^m]Pm=[p1m​,...,pQm​]（QQQ 是提示数量）。
    • 通过提示调整基础嵌入，得到模态特定的用户嵌入：

      eum=fu+sum(Pm)e_u^m = f_u + \text{sum}(P^m)eum​=fu​+sum(Pm)

      其中 sum(Pm)\text{sum}(P^m)sum(Pm) 是提示嵌入的元素求和。
  3. 多模态拼接：

    eu=[eu1,...,eu∣M∣]e_u = [e_u^1, ..., e_u^{|\mathcal{M}|}]eu​=[eu1​,...,eu∣M∣​]

(c) 用户-物品交互建模

  1. 模态特定评分：对每个模态 mmm，用交互函数 F\mathcal{F}F（如BPR或LightGCN）预测评分：

    yu,im←F(eum,eim)y_{u,i}^m \leftarrow \mathcal{F}(e_u^m, e_i^m)yu,im​←F(eum​,eim​)

  2. 最终评分：融合所有模态评分：

    yu,i=∑myu,imy_{u,i} = \sum_m y_{u,i}^myu,i​=m∑​yu,im​

2.2 弱模态增强训练

(a) 基础BPR损失

  • 构建训练三元组 (u,i,k)(u, i, k)(u,i,k)，其中 iii 是正样本，kkk 是负样本。
  • 优化目标：

    Lbpr=−∑(u,i,k)∈Dlog⁡σ(yu,i−yu,k)\mathcal{L}_{\text{bpr}} = -\sum_{(u,i,k) \in \mathcal{D}} \log \sigma(y_{u,i} - y_{u,k})Lbpr​=−(u,i,k)∈D∑​logσ(yu,i​−yu,k​)

    其中 σ\sigmaσ 是sigmoid函数。

(b) 弱模态正则化

  1. 弱模态识别：

    • 计算正负样本在每个模态的评分差异：

      du,ikm=yu,im−yu,kmd_{u,ik}^m = y_{u,i}^m - y_{u,k}^mdu,ikm​=yu,im​−yu,km​

    • 选择差异最小的模态为弱模态：

      mu,ik∗=arg⁡min⁡([du,ik1,...,du,ik∣M∣])m^*_{u,ik} = \arg\min([d_{u,ik}^1, ..., d_{u,ik}^{|\mathcal{M}|}])mu,ik∗​=argmin([du,ik1​,...,du,ik∣M∣​])

  2. 硬负样本生成：

    • 构造硬负样本 k∗k^*k∗，仅替换正样本 iii 在弱模态 m∗m^*m∗ 的嵌入：

      ek∗=[ei1,...,ekm∗,...,ei∣M∣]e_{k^*} = [e_i^1, ..., e_k^{m^*}, ..., e_i^{|\mathcal{M}|}]ek∗​=[ei1​,...,ekm∗​,...,ei∣M∣​]

  3. 弱模态正则化损失：

    Lweak=−∑(u,i,k∗)∈Dlog⁡σ(yu,i−yu,k∗)\mathcal{L}_{\text{weak}} = -\sum_{(u,i,k^*) \in \mathcal{D}} \log \sigma(y_{u,i} - y_{u,k^*})Lweak​=−(u,i,k∗)∈D∑​logσ(yu,i​−yu,k∗​)

(c) 总损失函数

L=min⁡Θ(Lbpr+αLweak+β∥Θ∥2)\mathcal{L} = \min_\Theta (\mathcal{L}_{\text{bpr}} + \alpha \mathcal{L}_{\text{weak}} + \beta \|\Theta\|^2)L=Θmin​(Lbpr​+αLweak​+β∥Θ∥2)

其中 α\alphaα 和 β\betaβ 是超参数，Θ\ThetaΘ 为模型参数。

3. 关键创新点

  1. 模态提示学习：用共享用户嵌入+模态提示高效建模多模态兴趣，减少内存开销。
  2. 弱模态增强：通过硬负样本增强弱模态的学习，平衡多模态表现。

4. 实验设置

  • 数据集：Amazon Baby和Clothing。
  • 评估指标：Recall@N和NDCG@N（N=10,20）。
  • 基线模型：VBPR、MMGCN、GRCN、SLMRec、DualGNN。
  • 超参数：
    • 提示数量 Q∈{1,2,3,4,5}Q \in \{1,2,3,4,5\}Q∈{1,2,3,4,5}。
    • α=0.01\alpha=0.01α=0.01, β=1\beta=1β=1。

实验结论总结与对应图表分析

1. 主要实验结论

  1. POWERec的有效性（RQ1）

    • POWERec在Baby和Clothing数据集上均取得了最佳性能（Recall@10和NDCG@10），显著优于基线方法（如VBPR、MMGCN、DualGNN等）。
    • 原因：
      • 通过共享的基础用户嵌入（single user embedding）和模态提示（modality prompts）建模多模态用户兴趣，减少了参数数量（Memory Cost更低）。
      • 弱模态增强训练（WE）通过惩罚不可靠模态的预测，提升了整体推荐性能。
    • 对应图表：
      • 表2：POWERec在Baby和Clothing数据集上的Recall@N和NDCG@N均优于基线方法（如Baby数据集上NDCG@10提升3.1%）。
      • 参数效率：POWERec的参数量（2.0 MB）显著低于DualGNN（3.7 MB）。

  2. 模块消融实验（RQ2）

    • 多模态提示学习（PO）：
      • PORec（仅含PO）优于BaseRec（无PO），证明模态提示能有效建模用户的多模态兴趣。
      • 表3：在Baby数据集上，PORec的NDCG@10比BaseRec提升8.3%。
    • 弱模态增强训练（WE）：
      • POWERec（PO+WE）进一步优于PORec（仅PO），表明WE能提升弱模态的学习效果。
      • 图3(b)：WE使得所有模态的用户评分差异（positive vs. negative）均大于0，说明弱模态兴趣被有效增强。

  3. 超参数分析（RQ3）

    • 权衡参数α：
      • 图2(a)(b)：α=0.01时性能最佳，过大（α=1）会因过度关注硬负样本（hard negatives）而损害整体性能。
    • 提示嵌入数量Q：
      • 图2(c)(d)：Baby数据集上Q=3时最佳，而Clothing数据集上Q=1足够，说明模态差异大的场景需要更多提示嵌入。

  4. 弱模态增强的可视化验证（RQ4）

    • 图3(a)(b)：
      • PORec在模态2（视觉）和模态3（文本）的评分差异接近0，表明存在弱模态。
      • POWERec通过WE显著提升了弱模态的评分差异。
    • 图3(c)(d)：
      • POWERec能更好区分正样本和硬负样本（hard negatives），验证了WE的有效性。

3. 核心贡献总结

  1. 多模态提示学习（PO）：
    • 通过共享用户嵌入+模态提示，高效建模多模态兴趣，减少内存开销。
  2. 弱模态增强训练（WE）：
    • 识别并增强不可靠模态（weak modality）的兴趣学习，提升整体鲁棒性。
  3. 通用性：
    • PO和WE可部署到现有方法（如DualGNN），进一步提升性能（表3中POWEDualGNN优于DualGNN）。

4. 未来方向

  • 当前假设硬负样本均为真实负样本，未来需处理假负样本（false negatives）的噪声问题。
