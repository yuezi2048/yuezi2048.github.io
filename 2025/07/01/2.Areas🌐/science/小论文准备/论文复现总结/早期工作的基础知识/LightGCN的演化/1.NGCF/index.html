NGCF

传统协同过滤（如基于矩阵分解的方法）仅利用用户 - 物品交互的全局统计信息，缺乏对高阶关联的挖掘。NCF（神经协同过滤） 首次将神经网络引入协同过滤，用多层感知机（MLP）学习用户、物品嵌入的非线性交互，突破了矩阵分解的线性限制，但未显式利用图结构信息

随着图神经网络（GNN）兴起，用户 - 物品交互可建模为二分图（用户、物品为节点，交互为边 ）。NGCF（神经图协同过滤） 在此背景下诞生，核心改进是：

  • 引入图结构：将用户 - 物品交互视为图，通过图卷积（GCN 变体）传播邻居信息，让嵌入学习能捕获用户 - 物品的高阶关联（如用户 A 喜欢物品 X，物品 X 被用户 B 喜欢，NGCF 可传递这种间接关联 ）。
  • 消息传递机制：定义从物品到用户（或反之）的消息构造公式（如 mu←i=1∣Nu∣∣Ni∣(W1ei+W2(ei⊙eu))\mathbf{m}_{u \leftarrow i} = \frac{1}{\sqrt{|\mathcal{N}_u||\mathcal{N}_i|}} \left( \mathbf{W}_1 \mathbf{e}_i + \mathbf{W}_2 (\mathbf{e}_i \odot \mathbf{e}_u) \right)mu←i​=∣Nu​∣∣Ni​∣​1​(W1​ei​+W2​(ei​⊙eu​)) ），融合邻居嵌入与自身嵌入的非线性交互，同时用归一化系数缓解度差异影响。

NGCF的模型如上图所示，传播过程分为message construction（消息构造）和message aggregation（消息聚合）两部分。

按照图中的结构图可以进行分以下三层：

  • Embeddings：对user和item的嵌入向量，用id来嵌入就可以了

E=[eu1,⋯ ,euN⏟users embeddings,ei1,⋯ ,eiM⏟item embeddings].\mathbf{E} = \left[ \underbrace{\boldsymbol{e}_{u_1}, \cdots, \boldsymbol{e}_{u_N}}_{\text{users embeddings}}, \underbrace{\boldsymbol{e}_{i_1}, \cdots, \boldsymbol{e}_{i_M}}_{\text{item embeddings}} \right].E=​users embeddingseu1​​,⋯,euN​​​​,item embeddingsei1​​,⋯,eiM​​​​​.

  • Embedding Propagation Layers：挖掘高阶连通性关系来捕捉交互以细化Embedding的多个嵌入传播层
  • Prediction Layer：用更新之后带有交互信息的 user 和 item Embedding来进行预测
    • 将用户的最终编码和物品表示的最终编码相乘得到用户评分矩阵类似的排序（编码方式不同于lightGCN）

message construction

对于连接的用户项对（u，i），论文将从i到u的消息定义为：
mu←i=f(ei,eu,pui)\mathbf{m}_{u \leftarrow i} =f(e_i,e_u,p_{ui})mu←i​=f(ei​,eu​,pui​)
具体的函数如下，puip_{ui}pui​是传播过程中的衰减因子
mu←i=1∣Nu∣∣Ni∣(W1ei+W2(ei⊙eu))\mathbf{m}_{u \leftarrow i} = \frac{1}{\sqrt{|\mathcal{N}_u||\mathcal{N}_i|}} \left( \mathbf{W}_1 \mathbf{e}_i + \mathbf{W}_2 (\mathbf{e}_i \odot \mathbf{e}_u) \right)mu←i​=∣Nu​∣∣Ni​∣​1​(W1​ei​+W2​(ei​⊙eu​))

此公式对应文中物品到用户的消息构造，W1\mathbf{W}_1W1​、W2\mathbf{W}_2W2​ 是可训练权重矩阵，ei\mathbf{e}_iei​、eu\mathbf{e}_ueu​ 分别为物品和用户嵌入，Nu\mathcal{N}_uNu​、Ni\mathcal{N}_iNi​ 是用户、物品的邻居集合，⊙\odot⊙ 表示哈达玛积（逐元素相乘 ）。

归一化系数在lightGCN中证明不可缺少，同时，lightGCN说明eie_iei​的自信息是冗余的

message aggregation

一阶聚合（用户侧）
eu(1)=LeakyReLU(mu←u+∑i∈Numu←i)\mathbf{e}_u^{(1)} = \text{LeakyReLU} \left( \mathbf{m}_{u \leftarrow u} + \sum_{i \in \mathcal{N}_u} \mathbf{m}_{u \leftarrow i} \right)eu(1)​=LeakyReLU(mu←u​+i∈Nu​∑​mu←i​)
这里 eu(1)\mathbf{e}_u^{(1)}eu(1)​ 是用户一阶聚合后的嵌入，mu←u\mathbf{m}_{u \leftarrow u}mu←u​ 可理解为用户自信息相关项，∑i∈Numu←i\sum_{i \in \mathcal{N}_u} \mathbf{m}_{u \leftarrow i}∑i∈Nu​​mu←i​ 是聚合来自邻居物品的消息，LeakyReLU\text{LeakyReLU}LeakyReLU 为激活函数。

通过一阶连通性建模增强表示，我们可以堆叠更多嵌入传播层来探索高阶连通性信息。高阶聚合公式如下（用户侧递推公式 ）
eu(l)=LeakyReLU(mu←u(l)+∑i∈Numu←i(l))\mathbf{e}_u^{(l)} = \text{LeakyReLU} \left( \mathbf{m}_{u \leftarrow u}^{(l)} + \sum_{i \in \mathcal{N}_u} \mathbf{m}_{u \leftarrow i}^{(l)} \right)eu(l)​=LeakyReLU(mu←u(l)​+i∈Nu​∑​mu←i(l)​)
lll 表示聚合的阶数（层数 ），mu←u(l)\mathbf{m}_{u \leftarrow u}^{(l)}mu←u(l)​、mu←i(l)\mathbf{m}_{u \leftarrow i}^{(l)}mu←i(l)​ 是第 lll 层时的自信息项和来自物品 iii 的消息项，通过堆叠多层这样的聚合来探索高阶连通性。

自信息和交互信息表示（消息在各层的计算 ）
{mu←i(l)=pui(W1(l)ei(l−1)+W2(l)(ei(l−1)⊙eu(l−1)))mu←u(l)=W1(l)eu(l−1)\begin{cases} \mathbf{m}_{u \leftarrow i}^{(l)} = p_{ui} \left( \mathbf{W}_1^{(l)} \mathbf{e}_i^{(l - 1)} + \mathbf{W}_2^{(l)} (\mathbf{e}_i^{(l - 1)} \odot \mathbf{e}_u^{(l - 1)}) \right) \\ \mathbf{m}_{u \leftarrow u}^{(l)} = \mathbf{W}_1^{(l)} \mathbf{e}_u^{(l - 1)} \end{cases}{mu←i(l)​=pui​(W1(l)​ei(l−1)​+W2(l)​(ei(l−1)​⊙eu(l−1)​))mu←u(l)​=W1(l)​eu(l−1)​​

lll 为层数，puip_{ui}pui​ 是控制边 (u,i)(u, i)(u,i) 传播衰减的系数，W1(l)\mathbf{W}_1^{(l)}W1(l)​、W2(l)\mathbf{W}_2^{(l)}W2(l)​ 是第 lll 层的可训练权重矩阵，ei(l−1)\mathbf{e}_i^{(l - 1)}ei(l−1)​、eu(l−1)\mathbf{e}_u^{(l - 1)}eu(l−1)​ 是物品和用户上一层（l−1l - 1l−1 层 ）的嵌入，用于递推计算当前层消息 。 每次传播时，聚合邻接结点信息时，邻接结点都是上次聚合更新后的结点信息。

具体来看高阶信息的堆叠过程

首先就是将i4、i5、i2三个物品的信息聚合到u2中，（其实在这个聚合过程进行的同时其他结点也都进行了相应的聚合邻接结点信息，例如在此时u1也聚合了i1、i2、i3的信息）

然后用u1和u2继续传播聚合给i2（此时i2结点在此时已经包含图三所有结点的信息），然后再将i1、i2、i3信息给u1。至此物品i4经过三层转手操作，通过路径上的结点一步步传递到u1手中。

为了便利与计算，其矩阵形式表示如下：
E(l)=σ((L+I)E(l−1)W1(l)+LE(l−1)⊙E(l−1)W2(l))\mathbf{E}^{(l)} = \sigma\left( (\mathcal{L} + \mathbf{I})\mathbf{E}^{(l-1)}\mathbf{W}_1^{(l)} + \mathcal{L}\mathbf{E}^{(l-1)} \odot \mathbf{E}^{(l-1)}\mathbf{W}_2^{(l)} \right)E(l)=σ((L+I)E(l−1)W1(l)​+LE(l−1)⊙E(l−1)W2(l)​)
注：原公式里的 ⨀\bigodot⨀ 若为哈达玛积（逐元素乘），用 ⊙\odot⊙ ；若公式中是普通矩阵乘，需结合原文确认，这里按常见 NGCF 设定用哈达玛积
L=D−12AD−12,A=[0RR⊤0]\mathcal{L} = \mathbf{D}^{-\frac{1}{2}}\mathbf{A}\mathbf{D}^{-\frac{1}{2}}, \quad \mathbf{A} = \begin{bmatrix} \mathbf{0} & \mathbf{R} \\ \mathbf{R}^\top & \mathbf{0} \end{bmatrix}L=D−21​AD−21​,A=[0R⊤​R0​]

  • L\mathcal{L}L 是图卷积中常用的归一化拉普拉斯矩阵（NGCF 里基于用户 - 物品二分图构造 ）。
  • A\mathbf{A}A 是二分图邻接矩阵，R\mathbf{R}R 是用户 - 物品交互关系矩阵（0 - 1 矩阵或带权矩阵，依 NGCF 设定 ），分块体现 “用户 - 物品”“物品 - 用户” 的二分结构。

eu∗=eu(0)∥⋯∥eu(L),ei∗=ei(0)∥⋯∥ei(L)\mathbf{e}_u^* = \mathbf{e}_u^{(0)} \|\cdots\| \mathbf{e}_u^{(L)}, \quad \mathbf{e}_i^* = \mathbf{e}_i^{(0)} \|\cdots\| \mathbf{e}_i^{(L)}eu∗​=eu(0)​∥⋯∥eu(L)​,ei∗​=ei(0)​∥⋯∥ei(L)​

∥\|∥ 表示嵌入拼接操作，将多层（从 0 到 L 层 ）的用户嵌入 eu(l)\mathbf{e}_u^{(l)}eu(l)​、物品嵌入 ei(l)\mathbf{e}_i^{(l)}ei(l)​ 拼接，作为最终用于预测的节点表示
