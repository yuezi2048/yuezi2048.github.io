一周突击面试准备计划

基于导师的专属建议，结合当前简历状态，边投边补快速拿下实习。

总体策略

阶段 时间 目标 交付物
Day 1 今天 项目讲述稿定稿 + 术语扫雷 两个项目的3分钟口述稿 + 逐条术语自问自答
Day 2 明天 Agent理论框架补齐 四种模式笔记 + 对比分析 + 评测维度清单
Day 3 后天 行为面试 + 产品研究 失败经历应答稿 + 携程产品分析
Day 4-7 冲刺 模拟面试 + 投递启动 每日1次自我录制 + 投递3-5家

第三步：Agent 全局理论框架（Day 2 补齐）

四种经典设计模式（Anthropic）

模式 说明 对应项目
Reflection Agent 检查自身输出，自我修正 BugVault 的 reflect_and_prevent_error 工具
Tool use Agent 调用外部工具获取信息或执行操作 Invoice Manager 的 8 个工具编排
Planning Agent 分解任务，制定多步计划 AgentLoop 的状态机本身就是 planning 的简化实现
Multi-agent 多个 Agent 协作完成复杂任务 BugVault 的双 Agent 分离架构（决策层+记忆层）

为什么自研不直接用 LangChain/Dify

完整 Agent 评测维度

维度 说明 BugVault 覆盖
检索效果 Recall@K、MRR、TopK命中率 ✅ context_relevance
生成忠实度 回答是否基于检索结果 ✅ faithfulness
工具选择准确率 是否调用了正确的工具 ❌ 未做（Invoice 场景）
端到端任务成功率 用户需求是否被完整满足 ❌ 未做
有害输出率 是否输出了不当内容 ❌ 未做（企业内系统风险低）
端到端延迟 用户从发起到收到回复的时间 ⚠️ 部分监控（运营看板）
单次任务成本 token 消耗、API 调用次数 ❌ 未做

第五步：投递策略 — 三梯队 + 边投边补

核心理念

绝对不能把所有心仪公司一次性投完。
把投递当成迭代过程，用前面的面试为后面的目标攒经验。

第一梯队：练手梯队（现在立刻投）

要素 说明
目标 非首选、但岗位匹配的练手公司（AI应用公司、相关技术非头部企业）
数量 3-5 家
目的 实战检验讲述稿、暴露短板、积累信心
时间 投递后 3-7 天面试
心态 拿到一个保底 offer 后，心态从「我能不能行」变为「我如何选更好的」

第二梯队：目标梯队（6 月底）

要素 说明
目标 最想去的公司（AI Agent明星创业公司、大厂AI创新部门）
时机 第一梯队 1-2 次面试后，讲述流畅、能化解 80% 深度追问时
优势 经过练手打磨的表达 + 针对目标公司微调的简历 + 已有保底底气

第三梯队：捡漏与保底（同步进行）

  • 大厂补录 / 秋招提前批：有合适的随时投
  • 内推是最高效渠道：找西北大学学长学姐，或通过 GitHub/即刻/Twitter 联系目标公司工程师

边投边补执行方案

补什么？

优先级 补什么 怎么做
🔴 最高 面试功 每天 1 次模拟录制 + 每次面试后立即复盘，没答好的当晚搞懂
🟡 重要 技术广度 2-3 小时速读 Anthropic “Building effective agents” 博客，做项目注解
🟡 重要 技术选型对比表 LanceDB vs Chroma, FastAPI vs Flask, MCP vs 传统 API 逐一准备
⚪ 加分 作品展现 保证 GitHub README 有架构图+快速开始；写一篇 BugVault 设计博客
